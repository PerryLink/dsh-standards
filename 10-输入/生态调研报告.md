## 一、核心结论：DSH 是什么

**DSH = DeepSeek Harness**，DeepSeek AI 于 2026-08-13 开源的 Agent 运行时（`deepseek-ai/deepseek-harness`，266,203★），核心理念 "Everything is a Plugin"（一切皆插件），插件运行时由 Cordis 驱动，CLI 为 `npx @deepseek-ai/dsh`（latest 0.2.1-rc.x）。

**官方唯一发现机制**：给插件仓库打 GitHub topic **`dsh-plugin`**（官方 README 原文要求）。插件判定硬标准（满足任一）：
1. README 含 `dsh plugin --profile <name> add <spec>` 安装命令；
2. `package.json` 声明 `dsh`/`engines.dsh` 字段或 cordis bundle 清单；
3. 被 `dsh-plugin-catalog`（npm format-1 索引）或社区市场收录。

## 六、方法、口径与局限

1. **数据获取**：GitHub Search API 按 topic 精确检索 + `stars:N..M` 分桶绕开单查询 1000 条上限；对高星与可疑项逐个抓取 raw README，用 `dsh plugin … add` / `plugin_manager` / `install_bundle` / `@deepseek-ai/dsh` 四类模式做安装证据判定；再以 dsh-market 目录快照（7,723 条）、dshplugin.org、dsh-tauri README 反向链接网络交叉验证。
2. **两个列表的口径**：列表一 = stars>10（1,650 个 topic 口径 / 970 个 catalog 口径）；列表二 = 6–10★ 区间（>5 且 ≤10，590 条 catalog 口径）。两者互补、不重叠。
3. **覆盖度**：>5★ 全量约 2,686 个仓库，本轮枚举核验约 77%（2,079 个），未覆盖的主要是 6–8★ 尾部；列表一只列**高置信度核验条目**，非全量 1,650 个的逐条展开。
4. **已知风险**：外部目录站 star 普遍滞后（dsh-TUI 滞后约 8 倍、dsh-deep-whale 约 6 倍）；存在幽灵条目（tabbit-browser/dsh-plugin 已 404 但目录仍收录）；monorepo 子包继承宿主 star（archify 条目 89,901★ 实为宿主仓库 star）；star 为瞬时值，会持续漂移。
5. **合规提示**：破限/红队类插件（dsh-purge、dsh-infinite-gen、dsh-unrestricted、dsh-redteam-model 等）安装前请自行合规审阅；市场收录不等于安全背书。
