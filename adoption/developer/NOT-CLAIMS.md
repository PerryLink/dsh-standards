# What not to claim

> The shortest page in the kit. If a sentence is not here, it is not a claim we
> support.

## Never say

| Don’t say | Say instead |
|---|---|
| “ENTRY certified” | “ENTRY runtime record, dated …, evidence …” |
| “FLOW passed” | “FLOW manual/runtime for J1/J2/J4/J6; J3/J5/J7/J8 not-run” |
| “BOOST optimized / faster” | “LEV-3 measured under <environment>; synthetic/loader-level” |
| “official / national standard” | “non-official community draft” |
| “secure / security audited” | “not a security audit; load-time consistency only” |
| “recommended / best / top” | “has an evidence record; you decide” |
| “production-ready” | “static/runtime evidence at this scope; no production guarantee” |
| “A-grade = ENTRY” | “A–D is a quality axis; ENTRY/FLOW/BOOST is adoption depth” |
| “client module loaded = UI works” | “client module loaded; rendering not tested” |
| “doctor passed = certified” | “doctor produced a report; certification is separate” |
| “expired but still valid” | “stale; re-run needed” |
| “withdrawn but still listed” | “withdrawn; history only” |

## Always include

- `status` + `scope` (dsh/cordis/commit) + `date`;
- an evidence link or artifact;
- the disclaimer: **非官方 · 非认证 · 非安全审计**;
- the limitation (synthetic, manual, static, blocked, partial).

## The one-sentence rule

**A label is a record of what was run, not a promise about what will happen.**
