# No endorsement requested

> This project does **not** ask DeepSeek, the Cordis team, or any market to
> endorse, adopt, host, certify, or recommend it.

- No logo, no “official”, no “partner”, no “approved by”.
- A citation is not an endorsement; a link is not an endorsement.
- If an official team uses any artifact, it does so as an independent experiment.
- If an official team disagrees, that is a valid result; the record stays as
  evidence, not as a claim of correctness.
- We do not ask for a meeting, a private channel, or a review SLA.
