# Outreach kit (v0.1)

> 非官方 · 非认证 · 非排名。先私聊、opt-in、匿名聚合；不公开失败名单。

## Data discipline

- Share aggregate/anonymized results; `n<5` not split.
- No failed plugin names, host logs, private chats, or absolute paths.
- Every number carries date/sample/method; no `verified` without a real external reviewer.
- No ranking, certification, official, “XX 已接受” pressure.

## WeChat (market maintainer, <=150 chars)

> X 你好，我们跑了 10 个公开插件的 entry 检查，发现你们的规则和我们的 checklist 有 3 处差异；我做了一页映射，可能帮作者少踩坑、减少你们 review。你们的规则是权威；你们不要求的项会标 warning/not-applicable/profile，不新增门槛。15 分钟听你挑错？不要求改规则、不 ranking。

## Email

Subject: `关于 entry 检查的 3 处差异，想请你挑错`

Body: same as WeChat; attach one-page mapping; no public naming.

## Official (<=200 chars)

> 你好，我们是一群社区维护者，做了一份插件 entry 检查的社区测试报告（非官方、不排名、不认证、不使用官方 logo）。想同步一页摘要，并请教命名/品牌展示有没有约束；不要求审批、不要求背书。官方不回复我们也继续，只按社区项目做；如措辞/品牌不妥，请指出，我们改。

## Per-object ask

- awesome / dsh-market: read-only sidecar + 10 third-party entries, 2-week pilot; no schema/UI/ranking change.
- dsh-desktop: Fabric RFC 0004 docs-only crosswalk; no runtime/contract change.
- dsh-web: one docs page; no code.
- dsh-TUI / dsh-go: 3–5 host compatibility data points; one contact; no implementation PR; no dsh-std replacement.
- DSH-better-sidebar: extension compatibility data; no API change; no reference-implementation claim.
- radar: four-state → evidence crosswalk; no verdict change.
- 0xsline / handbook: Related line / 10–15 line original section; no per-entry fields.
- skillhub: private pilot on skillhub-dsh, declared-only; no public/ official.
- Official: feedback/naming constraints only; no approval/endorsement.

## Do not

Rank, certify, use official/logo, name-and-shame, mass-DM, quote private chats, use “XX accepted” as pressure, or ask a market to change schema/UX.
