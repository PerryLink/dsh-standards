# Privacy and data handling

- Do not commit tokens, session data, private plugin code, or personal data.
- DCO `Signed-off-by` includes a name/email in public git history; use a
  dedicated email if needed.
- `contributors.json` records handle, level, and COI summary only. No address,
  phone, ID number, or private employment details.
- Evidence may include public repo URLs; do not add private dashboards.
- A takedown request for personal data: remove it from the current tree and
  record the action; git history may still contain it (say so honestly).
- This project is not a data controller for third-party plugins; it only stores
  what contributors publish.
