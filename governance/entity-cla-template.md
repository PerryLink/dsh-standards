# Entity CLA 模板（一页）

> **模板，不是法律意见。** 没有法律实体的一方不能签署；签署前应由组织法务复核。
> 用途：当公司/基金会/其他组织为代表其员工提交贡献时，明确授权、覆盖范围与许可。

---

**项目**：`PerryLink/dsh-standards`（DSH 插件规范与实践）
**贡献者条款版本**：`dsh-ct/1`（2026-11-01）
**Entity CLA 编号**：`ECLA-<YYYY>-<NNN>`

## 1. 组织

- 法定名称：`____________________`
- 注册地：`____________________`
- 授权代表（姓名/职务/邮箱）：`____________________`
- 覆盖的 GitHub 账号：`____________________`

## 2. 授权

签署方声明其有权代表上述组织，授权列明的 GitHub 账号以该组织名义提交贡献，并同意：

1. 对贡献适用 `dsh-ct/1` 的版权许可与专利 RF 许可；
2. 贡献不包含该组织无权披露的机密信息；
3. 组织对贡献的真实性、授权范围与出口管制/制裁合规负责；
4. 组织可提前 30 天书面通知终止本 CLA；终止前已提交的贡献许可继续有效。

## 3. 覆盖范围

- [ ] 其他：`____________________`

## 4. 排除

- 明确排除的材料/仓库：`____________________`

## 5. 签署

|---|---|---|---|---|
| 组织授权代表 | | | | |
| 项目接收人（organizer） | PerryLink | 创建者/组织者 | | |

## 6. 归档

签署后由 `ai-clerk` 计算 SHA-256，写入 `governance/contributors.json` 的 `entityCla` 字段；原件存放在私有合规目录，不公开个人信息。

## 7. 边界

- 本模板不构成对组织法律地位、授权真实性或专利状态的独立核查；
- 没有法人时，项目方只能做“声明 + 记录”，不能做“法律认证”；
- 若未来设立实体，本模板需由律师重写并重新签署。
